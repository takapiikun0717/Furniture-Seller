Description
I created this mod because, in Vanilla’s ‘Road to Vostok’, you cannot sell furniture; you have no choice but to throw it away.
Installation instructions
Place FurnitureSeller.vmz in the ‘mods’ folder and launch the game
Main features
Furniture featured in the furniture catalogue can be sold
The tax rate applied when selling can be changed via the MCM settings
Calculated based on the furniture’s value (you should be able to sell furniture from any mod)
Requirements
Metro Mod Loader  ver3.4.2 or later
Mod Configuration Menu  ver2.9.3 or later
Cash Money ver1.3.0 or later
