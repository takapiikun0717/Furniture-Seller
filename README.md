## Description
I created this mod because, in Vanilla’s *Road to Vostok*, you cannot sell furniture; you have no choice but to throw it away.

## Installation Instructions
1. Place `FurnitureSeller.vmz` in the `mods` folder.
2. Launch the game.

## Main Features
- Sell furniture featured in the furniture catalogue.
- Change the tax rate applied when selling furniture via the MCM settings.
- Furniture prices are calculated based on their value.
- Compatible with furniture from other mods.

## Requirements
- Metro Mod Loader **ver. 3.4.2** or later
- Mod Configuration Menu **ver. 2.9.3** or later
- Cash Money **ver. 1.3.0** or later
